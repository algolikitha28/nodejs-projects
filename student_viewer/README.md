# Student Record Viewer

A simple web-based **Student Record Viewer** built using **Node.js, Express.js, SQLite, HTML, CSS, and JavaScript**.

The application retrieves student records from a SQLite database through an Express.js API and displays them in a web-based table.

---

## 📌 Project Overview

This project demonstrates how a frontend application communicates with a backend server and retrieves data from a relational database.

### Application Flow

```text
Frontend (HTML + JavaScript)
            ↓
       Express.js API
            ↓
       SQLite Database
            ↓
       Student Records
            ↓
       HTML Table
